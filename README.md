## Privacy rules (read first)

1. Never paste grades, GPA, or score reports into an AI tool.
2. Never paste student ID numbers, Social Security numbers, or other personal identifiers.
3. Never paste classmates' names or work without their permission.
4. Treat every AI chat as public: don't share anything you wouldn't post on a bulletin board.

See [docs/privacy.md](docs/privacy.md).
